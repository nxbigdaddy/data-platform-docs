## 1. 引言

### 1.1 编写目的

本文档旨在明确数据中台系统的功能需求和非功能需求，作为系统设计、开发、测试和验收的依据。

### 1.2 项目背景

见《项目立项书》第1章。

### 1.3 术语定义

| 术语 | 定义 |
|------|------|
| 数据源 | 数据的来源系统，如MySQL、Oracle、API等 |
| 数据资产 | 经过治理的、有价值的数据资源 |
| 数据血缘 | 数据从产生到消费的全链路追溯关系 |
| 元数据 | 描述数据的数据，包括技术元数据和业务元数据 |
| 数据质量 | 数据的准确性、完整性、一致性、及时性 |
| 数据脱敏 | 对敏感数据进行处理，使其无法识别特定个人 |
| ETL | Extract（抽取）、Transform（转换）、Load（加载） |
| CDC | Change Data Capture，变更数据捕获 |

## 2. 总体描述

### 2.1 系统边界

```
┌─────────────────────────────────────────────────────────────┐
│                      数据中台系统                            │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐   │
│  │ 数据接入层 │  │ 数据存储层 │  │ 数据治理层 │  │ 数据服务层 │   │
│  └──────────┘  └──────────┘  └──────────┘  └──────────┘   │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐                  │
│  │ 数据分析层 │  │ 数据安全层 │  │ 系统管理层 │                  │
│  └──────────┘  └──────────┘  └──────────┘                  │
└─────────────────────────────────────────────────────────────┘
         ↑                      ↓
    数据源系统              数据消费者
  (MySQL/Oracle/           (业务系统/分析师/
```

## 3. 功能需求

### 3.1 数据接入层

#### 3.1.1 数据源管理

**需求编号**：REQ-DI-001
**需求名称**：数据源管理
**需求描述**：支持多种类型数据源的注册、配置和管理
**优先级**：P0
**验收标准**：
- 支持MySQL、PostgreSQL、Oracle、SQL Server等关系型数据库
- 支持MongoDB、Redis等NoSQL数据库
- 支持Kafka消息队列
- 支持HTTP/HTTPS API接口
- 支持FTP/SFTP文件服务器
- 支持本地文件、HDFS、S3对象存储
- 支持数据源连通性测试
- 支持数据源分类和标签管理

**功能列表**：

| 功能点 | 功能描述 | 优先级 |
|--------|---------|--------|
| 数据源注册 | 填写数据源基本信息和连接参数 | P0 |
| 数据源编辑 | 修改数据源配置信息 | P0 |
| 数据源删除 | 删除数据源（需校验无依赖） | P0 |
| 连通性测试 | 测试数据源连接是否正常 | P0 |
| 数据源分类 | 按业务域、系统类型分类管理 | P1 |
| 数据源标签 | 支持自定义标签 | P1 |

#### 3.1.2 数据采集任务

**需求编号**：REQ-DI-002
**需求名称**：数据采集任务管理
**需求描述**：支持配置和管理数据采集任务
**优先级**：P0
**验收标准**：
- 支持全量采集和增量采集
- 支持CDC实时同步
- 支持定时调度（Cron表达式）
- 支持任务依赖配置
- 支持失败重试机制
- 支持采集任务监控

**功能列表**：

| 功能点 | 功能描述 | 优先级 |
|--------|---------|--------|
| 任务创建 | 配置采集任务基本信息 | P0 |
| 字段映射 | 配置源表和目标表字段映射 | P0 |
| 数据过滤 | 配置采集数据过滤条件 | P1 |
| 调度配置 | 配置任务执行周期 | P0 |
| 依赖配置 | 配置任务前置依赖 | P1 |
| 任务启停 | 启动、暂停、停止任务 | P0 |
| 任务监控 | 查看任务执行状态和日志 | P0 |

#### 3.1.3 数据接入监控

**需求编号**：REQ-DI-003
**需求名称**：数据接入监控
**需求描述**：实时监控数据接入任务运行状态
**优先级**：P1
**验收标准**：
- 实时显示任务运行状态
- 显示数据采集量和速率
- 记录任务执行日志
- 异常告警通知

### 3.2 数据存储层

#### 3.2.1 数据仓库管理

**需求编号**：REQ-DS-001
**需求名称**：数据仓库管理
**需求描述**：支持数据仓库的分层设计和表管理
**优先级**：P0
**验收标准**：
- 支持数据分层（ODS/DWD/DWS/ADS）
- 支持数据库/Schema管理
- 支持表结构管理
- 支持表生命周期管理
- 支持存储容量监控

**数据分层定义**：

| 分层 | 名称 | 说明 |
|------|------|------|
| ODS | 操作数据层 | 原始数据，与源系统保持一致 |
| DWD | 明细数据层 | 清洗后的明细数据，主题域划分 |
| DWS | 汇总数据层 | 轻度汇总数据，按维度聚合 |
| ADS | 应用数据层 | 应用层数据，面向具体业务场景 |

#### 3.2.2 数据湖管理

**需求编号**：REQ-DS-002
**需求名称**：数据湖管理
**需求描述**：支持非结构化/半结构化数据存储
**优先级**：P1
**验收标准**：
- 支持文件上传和下载
- 支持文件夹管理
- 支持文件版本管理
- 支持文件元数据管理
- 支持文件预览（文本、图片、PDF等）

#### 3.2.3 存储资源监控

**需求编号**：REQ-DS-003
**需求名称**：存储资源监控
**需求描述**：监控存储资源使用情况
**优先级**：P1
**验收标准**：

- 存储容量告警

### 3.3 数据治理层

#### 3.3.1 数据标准管理

**需求编号**：REQ-DG-001
**需求名称**：数据标准管理
**需求描述**：建立和维护企业数据标准
**优先级**：P0
**验收标准**：
- 支持数据字典管理
- 支持数据标准定义（命名规范、数据类型、长度等）
- 支持标准版本管理
- 支持标准落地检查

**数据标准类型**：

| 标准类型 | 说明 | 示例 |
|---------|------|------|
| 命名标准 | 数据库对象命名规范 | 表名：t_业务域_实体名 |
| 数据类型标准 | 标准数据类型定义 | 金额：DECIMAL(18,2) |
| 编码标准 | 标准编码定义 | 性别：0-未知，1-男，2-女 |
| 度量标准 | 指标计算口径 | 日活跃用户：当日有登录行为的用户数 |

#### 3.3.2 元数据管理

**需求编号**：REQ-DG-002
**需求名称**：元数据管理
**需求描述**：自动采集和管理元数据
**优先级**：P0
**验收标准**：
- 自动采集技术元数据（表结构、字段信息等）
- 支持业务元数据维护（业务含义、负责人等）
- 支持元数据版本管理
- 支持元数据血缘分析
- 支持元数据搜索

**元数据类型**：

| 元数据类型 | 内容 | 采集方式 |
|-----------|------|---------|
| 技术元数据 | 表名、字段名、数据类型、约束等 | 自动采集 |
| 业务元数据 | 业务含义、业务规则、数据Owner等 | 人工维护 |
| 管理元数据 | 创建时间、更新时间、负责人等 | 自动采集 |
| 操作元数据 | 访问次数、更新时间、数据量等 | 自动采集 |

#### 3.3.3 数据质量管理

**需求编号**：REQ-DG-003
**需求名称**：数据质量管理
**需求描述**：建立数据质量规则，监控数据质量
**优先级**：P0
**验收标准**：
- 支持质量规则配置（完整性、准确性、一致性、及时性）
- 支持质量检查任务调度
- 支持质量问题告警
- 支持质量问题闭环处理
- 支持质量报告生成

**质量规则类型**：

| 维度 | 规则类型 | 示例 |
|------|---------|------|
| 完整性 | 非空检查 | 用户手机号不能为空 |
| 完整性 | 唯一性检查 | 用户ID不能重复 |
| 准确性 | 值域检查 | 年龄范围0-150 |
| 准确性 | 格式检查 | 手机号符合11位数字 |
| 一致性 | 关联检查 | 订单用户ID在用户表存在 |
| 及时性 | 时效检查 | 数据延迟不超过1小时 |

#### 3.3.4 数据血缘分析

**需求编号**：REQ-DG-004
**需求名称**：数据血缘分析
**需求描述**：追踪数据全生命周期流转关系
**优先级**：P1
**验收标准**：
- 自动解析ETL脚本生成血缘关系
- 支持字段级血缘追踪
- 支持血缘关系可视化展示
- 支持影响分析（上游变更影响范围）
- 支持血缘导出

**脱敏算法**：

| 算法 | 说明 | 示例 |
|------|------|------|

| 加密 | 可逆加密 | AES加密 |
| 替换 | 映射替换 | 姓名→随机姓名 |

## 4. 非功能需求

### 4.1 性能需求

| 需求项 | 需求描述 | 指标要求 |
|--------|---------|---------|
| PERF-001 | API响应时间 | 95%请求<500ms |
| PERF-002 | 即席查询响应 | 简单查询<3s，复杂查询<30s |
| PERF-003 | 报表加载时间 | 普通报表<5s，复杂报表<15s |
| PERF-004 | 数据同步延迟 | 实时同步<1s，准实时<5min |
| PERF-005 | 并发用户数 | 支持500+并发用户 |
| PERF-006 | 数据导入性能 | 支持10万条/秒导入 |
| PERF-007 | 系统吞吐量 | 支持10万QPS |

### 4.2 可用性需求

| 需求项 | 需求描述 | 指标要求 |
|--------|---------|---------|
| AVA-001 | 系统可用性 | ≥99.9%（年停机<8.76小时） |
| AVA-002 | 故障恢复时间 | RTO<30分钟 |
| AVA-003 | 数据恢复点 | RPO<5分钟 |
| AVA-004 | 计划停机 | 提前3天通知，安排在非业务高峰 |

### 4.3 安全性需求

|--------|---------|---------|

| SEC-003 | 会话管理 | 超时自动退出，单点登录 |
| SEC-004 | 数据传输 | 全链路HTTPS加密 |
| SEC-005 | 数据存储 | 敏感数据加密存储 |
| SEC-006 | 安全审计 | 全操作留痕，防篡改 |
| SEC-007 | 漏洞管理 | 定期安全扫描，及时修复 |
| SEC-008 | 等保合规 | 满足等保三级要求 |
