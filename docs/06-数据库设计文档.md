## 1. 引言

### 1.1 编写目的

本文档描述数据中台系统的数据库设计，包括逻辑模型、物理模型、表结构设计、索引设计等。

### 1.2 数据库选型

| 数据库类型 | 选型 | 用途 | 版本 |
|-----------|------|------|------|
| 关系型数据库 | PostgreSQL | 元数据、配置数据、业务数据 | 16+ |
| OLAP数据库 | ClickHouse | 海量数据分析、报表查询 | 24+ |
| 搜索引擎 | Elasticsearch | 全文检索、日志搜索 | 8.0+ |
| 缓存数据库 | Redis | 热点数据缓存、会话存储 | 7.0+ |
| 时序数据库 | InfluxDB | 监控指标、时序数据 | 2.7+ |
| 对象存储 | MinIO | 文件、非结构化数据 | 2024+ |

### 2.3 索引设计原则

1. **主键索引**：每个表必须有主键，使用BIGSERIAL自增
2. **唯一索引**：业务唯一字段添加唯一约束
3. **外键索引**：外键字段添加索引
4. **查询索引**：高频查询条件字段添加索引
5. **复合索引**：多条件查询使用复合索引
6. **分区表**：日志类大数据表按时间分区

## 4. Redis 缓存设计

### 4.1 缓存策略

| 数据类型 | 缓存Key | 过期时间 | 说明 |
|---------|---------|---------|------|
| 用户会话 | session:{token} | 30分钟 | JWT Token映射 |
| 用户信息 | user:{user_id} | 1小时 | 用户基本信息 |
| 数据源配置 | ds:{datasource_id} | 10分钟 | 数据源连接配置 |
| API限流 | rate_limit:{api_id}:{user_id} | 1分钟 | API调用限流计数 |
| 查询结果 | query:{hash} | 5分钟 | SQL查询结果缓存 |
| 元数据 | meta:table:{table_id} | 1小时 | 表元数据 |
| 字典数据 | dict:{dict_type} | 24小时 | 数据字典 |

### 4.2 Key命名规范

```
格式：业务域:模块:标识[:子标识]

示例：
- dmp:session:abc123def456          # 用户会话
- dmp:user:1001                      # 用户信息
- dmp:ds:config:10                   # 数据源配置
- dmp:meta:table:100                 # 表元数据
- dmp:api:rate:50:user:1001          # API限流
- dmp:query:md5_hash                 # 查询缓存
```
