## 1. 概述

### 1.1 接口规范

- **协议**：HTTPS
- **格式**：JSON
- **编码**：UTF-8
- **版本**：v1
- **Base URL**：`https://api.dmp.example.com/api/v1`

### 1.2 认证方式

采用 JWT Token 认证，在请求头中携带：

```
Authorization: Bearer {access_token}
```

### 1.3 响应格式

```json
{
  "code": 200,
  "message": "success",
  "data": {},
  "timestamp": 1711843200,
  "request_id": "req_abc123"
}
```

### 1.4 状态码

| 状态码 | 说明 |
|--------|------|
| 200 | 成功 |
| 400 | 请求参数错误 |
| 401 | 未授权 |
| 403 | 禁止访问 |
| 404 | 资源不存在 |
| 429 | 请求过于频繁 |
| 500 | 服务器内部错误 |

## 2. 认证接口

**接口**：`POST /auth/login`

**请求参数**：
