## 1. 环境搭建

### 1.1 开发环境要求

| 组件 | 版本要求 | 说明 |
|------|---------|------|
| Python | 3.11+ | 后端开发语言 |
| Node.js | 20+ | 前端开发环境 |
| PostgreSQL | 16+ | 关系数据库 |
| Redis | 7.0+ | 缓存数据库 |
| Docker | 24+ | 容器化环境 |
| Git | 2.40+ | 版本控制 |

### 1.2 后端环境搭建

```bash
# 1. 克隆代码仓库
git clone https://github.com/company/dmp-backend.git
cd dmp-backend

# 2. 创建虚拟环境
python -m venv venv

# 3. 激活虚拟环境
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate

# 4. 安装依赖
pip install -r requirements.txt
pip install -r requirements-dev.txt

# 5. 配置环境变量
copy .env.example .env
# 编辑 .env 文件，配置数据库连接等信息

# 6. 初始化数据库
alembic upgrade head

# 7. 启动开发服务器
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

### 1.3 前端环境搭建

```bash
# 1. 克隆代码仓库
git clone https://github.com/company/dmp-frontend.git
cd dmp-frontend

# 2. 安装依赖
npm install

# 3. 配置环境变量
copy .env.example .env.local
# 编辑 .env.local 文件

# 4. 启动开发服务器
npm run dev
```

### 1.4 Docker环境搭建

```bash
# 1. 启动基础服务
docker-compose -f docker-compose.dev.yml up -d

# 服务包括：
# - PostgreSQL: localhost:5432
# - Redis: localhost:6379
# - MinIO: localhost:9000
# - Kafka: localhost:9092
```

## 3. 开发流程

### 3.1 新功能开发流程

```
1. 创建功能分支
   git checkout -b feature/xxx develop

2. 开发功能
   - 编写代码
   - 编写测试
   - 更新文档

3. 本地测试
   - 运行单元测试
   - 运行集成测试
   - 代码审查

4. 提交代码
   git add .
   git commit -m "feat(xxx): xxx"
   git push origin feature/xxx

5. 创建Pull Request
   - 填写PR描述
   - 关联Issue
   - 请求代码审查

6. 合并代码
   - 审查通过
   - CI/CD通过
   - 合并到develop
```

### 3.2 代码提交规范

```bash
# 功能开发
git commit -m "feat(datasource): add connection pool support"

# 问题修复
git commit -m "fix(api): resolve timeout issue in large query"

# 性能优化
git commit -m "perf(query): optimize SQL execution with index"

# 代码重构
git commit -m "refactor(service): extract common logic to base class"

# 测试代码
git commit -m "test(datasource): add unit tests for connector"

# 文档更新
git commit -m "docs(api): update API documentation"
```

## 5. 常用命令

### 5.1 后端命令

```bash
# 数据库迁移

alembic upgrade head
alembic downgrade -1

# 运行测试
pytest                          # 运行所有测试
pytest tests/unit/              # 运行单元测试
pytest tests/integration/       # 运行集成测试

flake8 apps/                    # 代码风格检查
black apps/                     # 代码格式化

mypy apps/                      # 类型检查

# 运行服务
uvicorn main:app --reload
uvicorn main:app --host 0.0.0.0 --port 8000 --workers 4

# Celery任务
 celery -A apps.integration.tasks worker --loglevel=info
 celery -A apps.integration.tasks beat --loglevel=info
```

## 6. 常见问题

### 6.1 后端问题

**Q: 数据库连接失败**

```bash
# 检查数据库服务是否启动
docker-compose ps postgres

# 检查连接配置
cat .env | grep DATABASE

# 测试连接
psql -h localhost -p 5432 -U dmp_admin -d dmp_metadata
```

**Q: 迁移脚本冲突**

```bash
# 查看迁移历史
alembic history --verbose

# 删除冲突的迁移文件
rm alembic/versions/xxx_conflict.py

# 重新生成
alembic revision --autogenerate -m "fix conflict"
```

### 6.2 前端问题

**Q: 依赖安装失败**

```bash
# 清除缓存
npm cache clean --force
rm -rf node_modules package-lock.json

# 重新安装
npm install
```

**Q: 热重载不生效**

```bash
# 检查vite配置
# vite.config.ts
export default defineConfig({
  server: {
    hmr: true,
    watch: {
      usePolling: true  # Windows可能需要
    }
  }
})
```
