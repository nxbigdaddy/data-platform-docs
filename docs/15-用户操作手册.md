## 1. 系统概述

### 1.1 系统简介

数据中台系统（DMP）是企业级数据管理和服务平台，提供数据集成、数据治理、数据服务、数据分析等能力，帮助企业实现数据资产化、数据服务化。

### 1.2 功能模块

| 模块 | 功能说明 | 适用角色 |
|------|---------|---------|
| 数据集成 | 数据源管理、数据采集、数据同步 | 数据开发工程师 |
| 数据治理 | 元数据管理、数据质量、数据标准 | 数据管理员 |
| 数据服务 | API开发、服务目录、API网关 | 数据开发工程师 |
| 数据分析 | 即席查询、BI报表、数据大屏 | 数据分析师 |
| 数据安全 | 数据脱敏、访问控制、审计日志 | 安全管理员 |
| 系统管理 | 用户管理、角色权限、系统配置 | 系统管理员 |

## 3. 数据集成操作

### 3.1 数据源管理

#### 3.1.1 创建数据源

**操作步骤**：

1. 点击左侧菜单【数据集成】→【数据源管理】
2. 点击右上角【+ 新增数据源】按钮
3. 填写数据源信息：
   - **数据源编码**：唯一标识，如 `mysql_order`
   - **数据源名称**：显示名称，如 `订单数据库`
   - **数据源类型**：选择数据库类型（MySQL/Oracle/PostgreSQL等）
   - **连接配置**：
     - 主机地址：数据库IP或域名
     - 端口：数据库端口
     - 数据库名：数据库名称
     - 用户名：连接用户名
     - 密码：连接密码
4. 点击【测试连接】验证配置
5. 测试通过后，点击【确定】保存

#### 3.1.2 测试数据源连接

**操作步骤**：

1. 在数据源列表中找到目标数据源
2. 点击操作列的【测试连接】按钮
3. 等待测试结果
4. 查看连接状态：
   - ✅ 正常：连接成功
   - ❌ 异常：连接失败，查看错误信息

#### 3.1.3 同步元数据

**操作步骤**：

1. 在数据源列表中找到目标数据源
2. 点击操作列的【同步元数据】按钮
3. 系统开始扫描数据库结构
4. 等待同步完成
5. 查看同步结果：表数量、字段数量

### 3.2 数据采集

#### 3.2.1 创建采集任务

**操作步骤**：

1. 点击左侧菜单【数据集成】→【数据采集】
2. 点击【+ 新建任务】按钮
3. 填写任务信息：
   - **任务编码**：唯一标识
   - **任务名称**：显示名称
   - **任务类型**：批处理/流处理
4. 配置数据源：
   - 选择源数据源
   - 选择源表或填写查询SQL
   - 选择目标数据源
   - 选择目标表
5. 配置字段映射：
   - 系统自动匹配同名字段
   - 手动调整字段映射关系
   - 支持字段转换配置
6. 配置调度：
   - 调度类型：Cron表达式/间隔/一次
   - 设置执行时间
7. 点击【保存】

#### 3.2.2 启动/停止任务

**操作步骤**：

1. 在采集任务列表中找到目标任务
2. 点击操作列的【启动】或【停止】按钮
3. 确认操作
4. 查看任务状态变化

#### 3.2.3 查看执行记录

**操作步骤**：

1. 在采集任务列表中找到目标任务
2. 点击任务名称进入详情页
3. 切换到【执行记录】标签
4. 查看历史执行记录：
   - 执行时间
   - 执行状态
   - 数据量统计
   - 执行日志

## 4. 数据治理操作

### 4.1 元数据管理

1. 点击左侧菜单【数据治理】→【元数据管理】

#### 4.1.2 编辑业务元数据

**操作步骤**：

1. 在元数据详情页
2. 点击【编辑】按钮
3. 修改业务信息：
   - 业务名称
   - 业务描述
   - 数据Owner
   - 业务标签
4. 点击【保存】

### 4.2 数据质量

#### 4.2.1 创建质量规则

**操作步骤**：

1. 点击左侧菜单【数据治理】→【数据质量】
2. 点击【+ 新建规则】按钮
3. 选择规则类型：
   - **完整性**：非空检查、唯一性检查
   - **准确性**：值域检查、格式检查
   - **一致性**：关联检查、枚举检查

4. 配置规则：
   - 选择数据表
   - 选择检查字段
   - 配置检查条件
   - 设置阈值（警告/错误）

#### 4.2.2 执行质量检查

**操作步骤**：

1. 在质量规则列表中找到目标规则
2. 点击【执行检查】按钮
3. 等待检查完成
4. 查看检查结果：
   - 检查通过率
   - 问题数据统计
   - 问题数据样本

### 4.3 数据血缘

#### 4.3.1 查看血缘关系

**操作步骤**：

1. 点击左侧菜单【数据治理】→【血缘分析】
2. 选择数据表
3. 选择查看方向：
   - **向上追溯**：查看数据来源
   - **向下追溯**：查看数据去向
   - **影响分析**：查看变更影响范围
4. 查看血缘图谱
5. 点击节点查看详情

## 5. 数据服务操作

### 5.1 API开发

#### 5.1.1 创建API

**操作步骤**：

1. 点击左侧菜单【数据服务】→【API开发】
2. 点击【+ 创建API】按钮
3. 填写API信息：
   - **API编码**：唯一标识
   - **API名称**：显示名称
   - **请求方式**：GET/POST/PUT/DELETE
   - **API路径**：如 `/users`
4. 配置数据源：
   - 选择数据源
   - 选择数据表或编写SQL
5. 配置请求参数（可选）
6. 配置响应字段
7. 配置高级选项：
   - 超时时间
   - 缓存策略
   - 限流设置
8. 点击【保存】

#### 5.1.2 发布API

**操作步骤**：

1. 在API列表中找到目标API
2. 点击【发布】按钮
3. 确认发布
4. 查看API文档

#### 5.1.3 测试API

**操作步骤**：

1. 在API详情页
2. 点击【测试】标签
3. 填写请求参数

### 5.2 服务目录

#### 5.2.1 浏览API

**操作步骤**：

1. 点击左侧菜单【数据服务】→【服务目录】
2. 浏览API列表
3. 使用筛选条件查找API

#### 5.2.2 申请API权限

**操作步骤**：

1. 在服务目录中找到目标API
2. 点击【申请使用】按钮

## 6. 数据分析操作

### 6.1 即席查询

#### 6.1.1 执行SQL查询

**操作步骤**：

1. 点击左侧菜单【数据分析】→【即席查询】
2. 选择数据源
3. 在SQL编辑器中输入查询语句
4. 点击【执行】按钮
5. 查看查询结果

**常用SQL示例**：

```sql
-- 查询用户表前100条
SELECT * FROM dwd_user_info LIMIT 100;

-- 按省份统计用户数
SELECT province, COUNT(*) as user_count
FROM dwd_user_info
GROUP BY province
ORDER BY user_count DESC;

-- 查询最近7天注册的用户
SELECT * FROM dwd_user_info
WHERE register_date >= DATE_SUB(CURRENT_DATE, 7);
```

#### 6.1.2 导出查询结果

**操作步骤**：

1. 执行查询获取结果
2. 点击【导出】按钮
3. 选择导出格式：CSV/Excel
4. 确认导出

### 6.2 BI报表

#### 6.2.1 创建报表

**操作步骤**：

1. 点击左侧菜单【数据分析】→【BI报表】
2. 点击【+ 新建报表】按钮
3. 选择数据源
4. 拖拽图表组件到画布
5. 配置图表：
   - 选择数据表
   - 配置维度字段
   - 配置指标字段
   - 设置图表样式
6. 添加筛选器（可选）
7. 保存报表

#### 6.2.2 订阅报表

**操作步骤**：

1. 打开目标报表
2. 点击【订阅】按钮
3. 配置订阅：
   - 接收邮箱
   - 发送频率：每天/每周/每月
   - 发送时间
4. 保存订阅

## 7. 数据安全操作

### 7.1 数据脱敏

#### 7.1.1 配置脱敏规则

**操作步骤**：

1. 点击左侧菜单【数据安全】→【数据脱敏】
2. 点击【+ 新建规则】按钮
3. 选择敏感类型：
   - 手机号

   - 姓名
4. 选择脱敏算法：
   - 掩码（如：138****8888）
   - 哈希（不可逆）

5. 配置适用范围
6. 保存规则

## 8. 常见问题

### 8.1 登录问题

**Q: 忘记密码怎么办？**

A: 点击登录页的"忘记密码"链接，通过邮箱或手机号找回密码。

**Q: 账号被锁定怎么办？**

A: 联系系统管理员解锁账号。

### 8.2 数据源问题

**Q: 数据源连接测试失败？**

A: 请检查：
- 网络是否连通
- 连接信息是否正确
- 数据库服务是否启动
- 防火墙是否放行

**Q: 同步元数据没有表？**

A: 请检查：
- 数据库用户是否有查询权限
- 是否选择了正确的Schema

### 8.3 查询问题

**Q: SQL查询超时？**

A: 建议：
- 添加合适的WHERE条件
- 避免SELECT *
- 使用LIMIT限制返回条数
- 联系管理员优化查询

**Q: 查询结果为空？**

A: 请检查：
- SQL语法是否正确
- 查询条件是否合理
- 数据是否存在

### 8.4 API问题

**Q: API调用返回401？**

A: Token已过期，请重新获取Token。

**Q: API调用返回429？**

A: 请求过于频繁，请降低调用频率。
